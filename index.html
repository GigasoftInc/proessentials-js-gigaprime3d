GigaPrime3D Help

3D Chart

  1. Left button and drag to rotate.
  2. Shift + Left button drag to translate surface.
  3. Mouse Wheel zooms in and out entire scene.
  4. Middle button and drag adjusts light location. Desktop only; use the two light sliders here.
  5. Right click shows popup menu.

2D Contour, bottom left

  1. Left button and drag to zoom. Also zooms the 3D chart.
  2. Right click shows popup menu.
  3. Right click Undo Zoom to undo the 3D chart's zoom.

Sliders

Sliders allow manipulation similar to the click and drag built in UI.

Explode Z Axis

Adjusts the aspect ratio of the z axis to the xy axes. This process requires the triangle data to be re-constructed.

Cursor Tracking

Enables cursor prompt tracking of the mouse across the 3D surface. This setting may reset itself based on various UI behaviors.

Reduce Data

Provides more responsive cursor tracking.

This build

Runs the same C++ engine as the desktop control, compiled to WebAssembly, with the surface on WebGPU.

Gigasoft plots this data faster than any other known 3D chart.
